# Maintenance review, November 2026

Reviewed NMF v0.1.5 at `e380029` on November 19, following the [September review](maintenance-review-2026-09.md). Findings below refer to that revision. The highest priorities are preserving the exact selected filesystem object, honoring overwrite decisions, and keeping credentials out of diagnostics. The largest measured interactive costs come from copying a whole collection for each selected item or rendering a whole preview to display a small viewport.

The [implementation results](#implementation-results) cover the fixes and measurements after this review.

## Fix first

| Finding | Evidence and scope | Suggested fix and acceptance check |
| --- | --- | --- |
| A selected name can resolve to its sibling | A Linux copy job given the listed path for `report ` copied the name and contents of `report` when both existed. Permanent delete and move use the same trimming resolver. Rename also trims the listed source while resolving its native path. The Windows Shell path normalizer separately strips Unicode whitespace before operations including recycle. [Job resolver](../internal/jobs/execution_path.go), [delete](../internal/jobs/delete.go), [rename](../internal/fileinfo/rename.go), [Shell paths](../internal/shellmenu/windows_path.go) | Separate parsing typed input from consuming an enumerated path. Preserve every character through backend and shell handoff. Exercise copy, move, rename and both delete modes on distinct siblings in temporary directories, including a Windows-native Unicode whitespace case. |
| Renaming a copy conflict can authorize overwriting a newer file | On a second conflict, the loop updates the destination path and keeps the first destination's stat. A Linux copy with source mtime 2000, initial destination 1000 and renamed destination 3000 (Unix seconds) presented 1000 in the second prompt. “Overwrite if newer” replaced the file at 3000. [Conflict resolution](../internal/jobs/conflict.go) | Resolve the new destination's metadata and type on each retry. Assert the timestamp shown and the bytes retained by the newer destination. |
| Debug logging can disclose credentials | Path Edit logs the raw submitted SMB URL before removing user information. The invalid-input branch also logs raw input. Separately, the SMB and archive password entries pass physical key events to the normal key logger, which includes key names and modifier transitions. Debug output can go to stderr and a persistent log. [Path Edit](../list_controls.go), [path handling](../directory_loading.go), [entry events](../internal/ui/line_edit_dialog.go), [key logging](../internal/keymanager/keymanager.go), [logging destinations](../debug_logging.go) | Omit raw path input before parsing and omit key identities throughout sensitive entry. Exercise accepted and rejected URLs and password entry with a capturing test logger. |
| File open can block the Fyne event thread on an entire remote file | Enter probes every ordinary file synchronously. On direct SMB, `IsSupportedArchive` stages the whole file in a temporary file, even for an ordinary video. Opening a recognized archive stages it again. Selecting archives to extract probes each candidate on the event thread too. Credential renewal can wait for a dialog that needs this same thread. [OpenFile](../list_controls.go), [archive selection](../jobs_ui.go), [probe and staging](../internal/fileinfo/archive_vfs.go), [credential dialog](../internal/ui/smb_login_dialog.go) | Move detection and preparation to cancellable work. Use bounded detection where the format allows it and carry a staged file into the operation that needs it. Check bytes transferred and UI responsiveness for a large non-archive, an archive and a renewed credential prompt. |
| Preview cancellation stops short of direct SMB I/O | Preview resolves the provider with a context, then calls plain Stat and Open. Direct SMB starts those calls with a background context. Canceling the viewer invalidates its callback but can leave its read or prompt pending. [Preview](../internal/fileinfo/preview_file.go), [SMB methods](../internal/fileinfo/smbfs_linux.go), [context-aware open](../internal/fileinfo/vfs.go) | Pass the viewer context into stat and open on the already resolved VFS. Exercise cancellation during a stalled preview read through the viewer entry point. |

## Browser and watcher correctness

- **A quiet directory can stay out of date.** The loader reads before the native watch is installed. Starting the watcher seeds its baseline from the displayed list and performs no initial reconciliation. In a Linux fixture, a file created in that gap was still absent after 650 ms. Both the subscriber and change channels also discard the incoming update when full. The native event loop rereads only after another event. Reconcile after registration and retain the latest full snapshot while a consumer is busy. Derive deltas from the last accepted state so a skipped intermediate snapshot cannot strand the display. Preserve run and window generation checks. [Watcher start and delivery](../internal/watcher/watcher.go), [hub delivery](../internal/watcher/hub.go)
- **Creation can break sorting on the next watcher update.** With name sort, creating `a` beside `b` displays `a,b`. A size-only change to `b` can then display `b,a`. Upsert sorts the visible slice but leaves the baseline in insertion order. The modify-only path reuses that baseline. **Rename also bypasses the filter**. Renaming `a.txt` to `a.bin` leaves it in a `*.txt` view. Both behaviors reproduced against the model. Keep one ordered baseline, then derive visible membership. Preserve the intended rename cursor/order behavior for remaining visible rows. [Browser mutations](../internal/browser/model.go), [create](../create_directory_ui.go), [rename](../rename_ui.go)
- **Visible filter state has two owners.** Toggle checks the window's model alongside application-wide Current and Enabled. Apply different filters in A and B, then clear B. A can still display its filter while Toggle in A does nothing. A separate initial-load test with a saved enabled filter also showed entries outside its pattern. Keep the active and toggle-back filter on the window, with shared history and startup preferences in persisted state. [Filter commands](../list_controls.go), [window construction](../bootstrap.go)
- **The hidden-file setting has no effect on listing.** JSON and Starlark populate `ShowHiddenFiles`. The directory loader and watcher include hidden entries regardless. The documented default is false, so implementing it changes today's visible behavior. Exercise initial display, watcher updates and cached display under both values. [Configuration](configuration.md), [loader](../internal/browser/directory_loader.go), [watcher snapshot](../internal/watcher/hub.go)
- **Cursor memory can evict an unrelated directory on update.** Saving an existing key at capacity first evicts the oldest key, then overwrites the existing one. Saving a new key when already above a reduced limit removes only one before adding one. Evict on insertion or explicit limit reduction and check the final count. [Cursor persistence](../directory_loading.go)

Precompute the roots and relative components, apply all rebases in result order, then rank and prune once. Test nested roots, duplicate destinations, usage counts and cross-provider descendants. ## Other correctness and maintenance findings

- **A partial read error can count as an ordinary mismatch.** A test reader returning one byte followed by a non-EOF error, compared with two bytes, returned `false, nil`. The UI receives no error count for this pair. Check read errors before the byte/length mismatch. Destination metadata failures during enumeration are also skipped, potentially classifying an unreadable entry as missing. Track lookup failure separately from absence. [Directory comparison](../internal/filecompare/compare.go)
- **Directory metadata is applied too early.** Under an ordinary Linux account, copying a populated mode-0555 directory failed creating the children and left an empty, read-only destination. Extracting a tar with the directory header before its child preserved the child's mtime but lost the directory's requested mtime. Create new directories with sufficient working permission and finalize their own metadata after populating descendants. Preserve existing destination directory permissions. [Directory transfer](../internal/jobs/transfer.go), [extraction](../internal/jobs/archive_extract.go)
- **Detected archives and navigable archive paths disagree.** A valid ZIP named `backup.blob` passed content detection, then listing its generated virtual root failed because the path parser recognizes archive boundaries only after selected suffixes. Tree Parent mode also uses the host parent operation on local archive paths and can generate `a.zip!` instead of the virtual root `a.zip!/`. Make detection and navigation agree and route archive-parent handling through the existing portable helper. Retain the test for ordinary directory names ending in an exclamation mark. [Parser](../internal/fileinfo/archive_path.go), [open](../list_controls.go), [tree parent](../internal/ui/tree_platform_unix.go)
- **The last popped key handler can retain a closed viewer.** Removing the top entry shortens the slice while its backing array still contains the handler, which holds the viewer and its preview. The stale slot was observed in an isolated test. Clear the removed tail, e.g. with slices.Delete. Preserve token-based removal and focus restoration. [Handler removal](../internal/keymanager/keymanager.go), [viewer handler](../internal/keymanager/fileviewer_handler.go)
- **UTF-16 text can open as binary.** A BOM-marked UTF-16LE file containing ABC decoded correctly but still had Binary set. Raw NUL detection then disables the Text pane. Classify confidently recognized UTF-16 using the decoded content and test the complete preview result. [Preview classification](../internal/fileinfo/preview_file.go), [viewer panes](../internal/ui/file_viewer_dialog.go)
- **Cancel can leave a single-worker job blocked, or report a canceled job as failed.** Code inspection shows direct-SMB job sessions dial with a background context, so a canceled transfer waiting on I/O can delay the next job. Separately, the worker recognizes only its private canceled error. Unix trash can return context.Canceled, which becomes Failed. Bind job sessions to the job context and share cancellation classification across transfer, extract and delete. The directory loader's free-space query also opens a separate direct-SMB session without the load context. [Job sessions](../internal/jobs/execution_path.go), [SMB provider](../internal/fileinfo/smbfs_linux.go), [terminal state](../internal/jobs/manager.go), [trash](../internal/fileinfo/trash_unix.go)
- **Backward search at document start can return the current match again.** With two lines each containing `a`, forward search to the first match then previous search returned line one again with no wrap indication. Represent the position before the first character distinctly and test forward/backward wrap at both ends. [Viewer search](../internal/ui/file_viewer_text_grid.go)
- **Concurrent Windows packaging can mix architectures.** Both recipes use the same intermediate executable and back up and restore the same Fyne metadata. The target-specific .NOTPARALLEL declaration serializes prerequisites of those targets, which have none. On a temporary copy with a packaging stand-in, concurrent amd64 and arm64 targets overlapped, one move failed, and the amd64 output path contained the arm64 marker. The release workflow runs these targets sequentially. Isolate intermediate outputs or serialize the whole packaging section. [Makefile](../Makefile), [release workflow](../.github/workflows/release.yml)

## Scope of structural changes

1. **Consolidate selection and listing queries at their consumers.** The browser already owns ordered selection and atomic cursor lookup. Several commands independently reconstruct those answers from snapshots. Migrate drag, preview and command context first. The measured drag alternative exercises the existing model method.
2. **Simplify watcher delivery around complete snapshots.** A queue of snapshots followed by a queue of deltas requires two overflow policies and a separate baseline generation. Introduce latest-state delivery with explicit snapshot ownership and one reconciliation after watch registration. Exercise slow windows, independent resets and unsubscribe during a broadcast before removing any generation guard.
3. **Keep keyboard responsibilities narrow while reducing wiring.** Startup supplies the same FileManager to nine named ports. The constructor copies them into a second descriptor and validates them, and handler construction validates again. One validated descriptor can keep the existing small test interfaces and the separate Starlark command interface. This is lower priority than the lifecycle and data-integrity fixes. [Startup](../bootstrap.go), [ports](../internal/keymanager/mainscreen_dependencies.go), [handler](../internal/keymanager/mainscreen_handler.go)
4. **Remove duplicate list state in the UI.** History and destination dialogs maintain a filtered array and a second Fyne StringList synchronized from it. The directory jump dialog already renders its array directly via widget.NewList. Incremental search additionally copies every FileInfo into its matches for an empty query and keeps both arrays after hiding. Reference the original snapshot for empty search, store match indices for other queries and release the snapshot on close. [History](../internal/ui/history.go), [destinations](../internal/ui/destination_picker.go), [directory jump](../internal/ui/directory_jump_dialog.go), [search](../internal/ui/incremental_search.go)
5. **Trim the watcher port immediately.** Three of its six required methods, GetFiles, UpdateFiles and RemoveFromSelections, have no watcher callers. The three in use are GetCurrentPath, GetUnfilteredFiles and ApplyChanges. [Watcher interface](../internal/watcher/watcher.go)

## Validation

Linux passed `make test-all`, `make test-race`, and `go vet -tags migrated_fynedo ./...`. The separate temporary fixtures exercised ordinary jobs in disposable directories, model and Fyne test-driver behavior, and isolated computation. The Windows drag benchmark exercised the shared candidate selector on Linux. The packaging concurrency fixture used a stand-in packager. Live SMB, native Windows and macOS UI, blocking credential renewal on a real server, and end-to-end frame times remain unmeasured in this review.

Suggested sequence is to protect name identity and conflict retries, remove sensitive logging, then fix blocking I/O and watcher convergence. The drag and cursor lookup changes are small independent performance wins. Viewer virtualization and watcher delivery each deserve separate changes with their own before/after fixtures.

## Implementation results

The maintenance branch implemented the findings above. The integrated application and its regression tests were validated at `8519387`. The main user-visible default change is hidden-file visibility. To retain the former listing, set `ui.showHiddenFiles` to true.
